# Day 4 - Introduction to Web Development (HTML & CSS)

## Website and Web Pages

### What is a Website?

A website is a collection of web pages that are connected and accessible through the internet.

### What is a Web Page?

A web page is a single document that is displayed in a web browser.

### Examples of Websites

* Amazon
* Wikipedia
* Google
* W3Schools

## Types of Websites

### 1. Static Website

* Contains fixed content.
* Built using HTML and CSS.
* Content remains the same unless manually updated.

### 2. Dynamic Website

* Content changes dynamically.
* Uses databases and programming languages.
* Can display different content for different users.

## Frontend vs Backend

| Frontend              | Backend                              |
| --------------------- | ------------------------------------ |
| Visible to users      | Runs on the server                   |
| HTML, CSS, JavaScript | PHP, Python, Java                    |
| User Interface (UI)   | Database Handling and Business Logic |

## Web Development Technologies

* HTML
* CSS
* JavaScript
* Databases
* Web Servers

## Introduction to HTML

### What is HTML?

HTML (HyperText Markup Language) is the standard markup language used to create the structure and content of web pages.

**Note:** HTML is not a programming language; it is a markup language.

### HyperText

Refers to the links that connect web pages.

### Markup Language

Refers to the tags used to structure content, such as `<h1>` and `<p>`.

## HTML Tags Learned

### Heading Tags

Used to define headings in a document.

```html
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
```

### Other HTML Tags

* Paragraph Tag: `<p>`
* Line Break Tag: `<br>` or `<br />`
* Center Tag: `<center>`
* Horizontal Rule: `<hr>` or `<hr />`
* Preserve Formatting Tag: `<pre>`
* Non-Breaking Space: `&nbsp;`
* List Tags: Ordered and Unordered Lists

# Introduction to CSS

## What is CSS?

CSS (Cascading Style Sheets) is used to style and design web pages.

## Methods to Include CSS

### 1. Inline CSS

* Applied directly within an HTML element.
* Has higher priority than internal and external CSS.

### 2. Internal CSS

* Written inside the `<style>` tag within the HTML file.

### 3. External CSS

* Written in a separate `.css` file and linked to the HTML document.

### Important Rule

If you want to override CSS priority, you can use the `!important` keyword.

## CSS Selectors Learned

* Universal Selector (`*`)
* Child Selector (`>`)
* Group Selector (`,`)
* Descendant Selector (space)
* Adjacent Sibling Selector (`+`)
* Pseudo Class (`:hover`, `:focus`, etc.)
* Pseudo Element (`::before`, `::after`, etc.)

## CSS Properties Covered

* Text Properties
* Background Properties
* Border Properties
* Box Model
* Positioning
* Display Properties
* Responsive Design using Media Queries
* Animations
